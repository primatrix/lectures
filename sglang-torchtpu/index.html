AFTER hook 改返回值，原函数仍先执行

def wrapper(*args, **kwargs):
    result = original_fn(*args, **kwargs)
    modified = hook(result, *args, **kwargs)
    return (modified if modified is not None
            else result)

符合实验开关和算法条件时，返回 TPU worker 类；否则保留原结果。

类型执行语义
BEFORE先 hook，可修改参数
AFTER先原函数，再修改结果
AROUNDhook 决定是否、何时调用原函数
REPLACE默认不调用原函数

显式通信 · Torch API → SGLang 封装 → TPU 后端

求和、收集、归约分片，都有显式 API

torch.distributed 接口

import torch.distributed as dist
g = tp_group.device_group

# 部分和 → 完整值；原地更新 y
dist.all_reduce(y, group=g)

# 分片 → 完整值；按 dim 0 收集
dist.all_gather_into_tensor(full, shard, group=g)

# 部分和 → 求和后的分片
dist.reduce_scatter_tensor(out, partial, group=g)

三个独立示例；full / out 已分配。collective 需要 group 内各 rank 对应参与。
