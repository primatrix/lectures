Chapter 03 / Kimi Delta Attention

KDA：把完整档案变成会更新的工作记忆

Full Attention 保存每个 token 的 K/V；KDA 让历史持续写入固定大小的状态。它不试图逐字保存，而是维护一份能被当前 query 读取的记忆摘要。

Chapter 05 / Attention Residuals

普通 residual 像一根不断传递的接力棒；AttnRes 把此前 block 的表示保留下来，让当前 token 按内容选择要重新读取哪一份。

Chapter 08 / Architecture → systems

K3 没有消灭成本，而是把成本变得更可控

每个模块都把一种难以扩展的 dense cost，换成更结构化的 state、selection 或 routing。理解这些新成本，正是后续 Prefill/Decode、Roofline 和 MoE 优化的起点。

Three axes · three cost shifts architecture is a systems contract
Across tokens

记得更久

大多数层维护固定工作记忆，必要时仍能全局查阅历史。

新成本：recurrent-state 更新、偶发全局 attention 与两类 cache 的协同。
Across depth

回看更早

当前层按内容选择此前 block 的表示，减少单一 residual stream 的信息瓶颈。

Attention Residuals
新成本：block representation 的保存、读取与 depth reduction。
Across channels

更会分工

公共知识走 shared path，专长计算在较窄 latent space 中稀疏激活。

Stable LatentMoE
新成本：routing、dispatch/combine、专家负载与低精度 weight streaming。
